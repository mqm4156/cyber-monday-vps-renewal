## Size for your busiest hour, not the discount

The sizing rule that works is to take last year's busiest hour, add headroom to it, and test that number. Not the average day, not the order count from a good week in March. Adobe's numbers show why the peak is a different animal: on Cyber Monday 2025, US shoppers spent $16 million every minute between 8 and 10 pm, and Adobe's 2026 forecast puts Black Friday online spend in the US at $12.9 billion.

The sequence that avoids a crash:

1. Pull the busiest hour from last November and use it as your target load.
2. Load test several weeks before the sale, not the week of.
3. Fix what breaks, then test again to confirm the fix worked.
4. Set a change freeze a few days before the peak.
5. Do every upgrade before that freeze, because some resizes require a reboot or a power-off.

That last point catches people. DigitalOcean's resize needs the Droplet powered off; Vultr only resizes upward; Akamai Cloud resizes both ways warm. If your provider's resize path involves downtime, doing it on November 29 is not an option.

A CDN does not rescue a weak server. It offloads images, scripts and stylesheets; the cart, checkout and account pages are dynamic requests that still hit your box. Cache the pages, test the checkout flow specifically, and leave capacity for the requests a CDN can't absorb.

If a single server at its top tier still can't hold the peak, the answer is more instances behind a load balancer, which is a different architecture rather than a bigger plan. For most small and midsize stores, one properly sized VPS is enough.

## Four things that go wrong when buying on Cyber Monday

**The discount is for new customers.** Most VPS promotions are acquisition offers, and some providers say so outright: Liquid Web's promo applies to new accounts and excludes upgrades of existing servers. If you're already a customer, the sale probably isn't for you.

**It covers the first billing cycle only.** HostAdvice's guidance on renewal terms is the same as everyone else's experience: confirm the regular rate you'll pay once the promo ends, because the promo price is temporary by design.

**The sale can end on the day.** ScalaHosting's 2025 run finished on December 1, which made Cyber Monday the last day rather than the best one. Bluehost's 2026 holiday promotion ends November 30. Waiting past the weekend is a real risk; waiting for a further cut usually isn't rewarded.

**Resizing during peak is the wrong move.** Some plan changes need a reboot. Do the upgrade before the change freeze, then load test the new capacity, then leave the server alone until the traffic passes.
